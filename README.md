# Student Placement Tracker

A simple Java-based application to track DSA problems for placement preparation.

## Features

- Add DSA problems
- Display all problems
- Mark problems as solved
- Search problems by category
- Track problem difficulty

## Technologies Used

- Java
- Git
- GitHub

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Compile the program:

```bash
javac Main.java
