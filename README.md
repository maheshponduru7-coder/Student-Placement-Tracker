# Student Placement Tracker

A Java console-based application to track coding problems
for placement preparation.

## Features

- Add problems
- Display all problems
- Mark problems as solved/unsolved
- Search by problem name
- Search by category
- Update problems
- Delete problems
- Overall progress tracking
- Difficulty-wise progress
- Category-wise progress
- Filter by difficulty
- Filter by solved/unsolved status
- Sort by ID
- Sort by difficulty
- File handling for permanent data storage
- Input validation

## Technologies Used

- Java
- OOP
- ArrayList
- File Handling
- Searching
- Sorting

Compile:

java -cp src Main
